# Knight_RPC 

**Knight_RPC** 是一个基于 C++ 实现的高性能异步远程过程调用（RPC）框架。项目专注于底层网络通信效率与资源管理的严谨性，采用经典的主从 Reactor 多线程模型，适用于高并发后端服务场景。

## 🌟 核心特性

* **高性能网络引擎**：基于 Linux **Epoll** 实现的 Reactor 模式，支持 **Edge-Triggered** 水平触发与非阻塞 IO，极大提升了并发处理能力。
* **主从多线程模型**：采用 **Main-Sub Reactor** 架构，主线程负责连接接入（Accept），子线程池负责 IO 读写，实现监听与处理的深度解耦。
* **严谨的资源管理**：全流程践行 **RAII** 思想，利用智能指针与包装类管理 Socket、Buffer 及线程资源，杜绝内存泄漏。
* **高效序列化**：集成 **Google Protobuf**，提供极低开销的数据序列化与反序列化，支持复杂的跨平台消息定义。
* **类型擦除技术**：服务端通过类型擦除（Type Erasure）技术，实现了对异构 Service 接口的统一调度与管理。
* **健壮的协议设计**：自定义二进制私有协议，通过『固定包头 + 载荷长度』设计，完美解决 TCP 粘包与断包问题。

---

## 🏗️ 逻辑架构

项目采用层次化设计，确保各组件高度解耦：

1.  **服务层 (Service Layer)**：用户定义的具体业务逻辑。
2.  **客户层 (client Layer)**：向服务层发起任务调用
3.  **网络层 (Network Layer)**：基于 Reactor 模式的事件触发驱动引擎。
4.  **RPC 层 (RPC Layer)**：负责代理（Proxy）生成、序列化及任务分发。

## 🚀 快速开始

### 环境依赖
* Google Protobuf
* CMake (3.10+)
* G++ (支持 C++11 及以上)

### 编译运行
内置一键编译的脚本，只需要执行./autobuild.sh 
即可一键编译成lib库，考虑到用户可能基于客户端/服务端开发，所以没有硬链接所有lib库，可以根据自己需要链接相应库

运行逻辑可以参考example目录下的样例
